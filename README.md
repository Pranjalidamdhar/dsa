# Data Structures and Algorithms (DSA)

Welcome to my **Data Structures and Algorithms (DSA)** repository! This repository contains my solutions to various DSA problems solved while practicing on coding platforms like **LeetCode**, along with explanations, approaches, and time & space complexity analysis.

## 📌 About

The goal of this repository is to:

- Strengthen problem-solving skills.
- Improve coding proficiency in Java.
- Prepare for technical interviews and coding assessments.
- Track my DSA learning journey.

---

## 🛠️ Language Used

- Java

Each problem folder contains:
- Java solution (`.java`)
- `README.md` with:

  - Approach

  - Space Complexity
